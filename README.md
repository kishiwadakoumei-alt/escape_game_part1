# BEYOND THE DOORS ─ 第1ステージ「封印された魔法図書館」

オリジナルの2Dポイント＆クリック型脱出ゲームです。**8つの謎を解いて、最後の封印の扉を開くところまでプレイ可能**です。

本作は、観察・論理・道具の活用・情報統合・発想の転換をゲーム内で練習できるように設計した自主制作作品です。SCRAP・名探偵コナンの公式ゲームとは関係ありません。公演の内容を転載・再現していません。

## 遊び方

1. 「探索をはじめる」を押します。
2. 背景上の光る印、または背景の下に並ぶ**調査ボタン**を押して仕掛けを調べます。
3. 本を並べる、図形を選ぶ、紙片を交換する、ステンドグラスを回すなどの操作で謎を解きます。
4. 入手したアイテムは**持ち物欄で選択**してから、必要な仕掛けで使います。
5. 自動記録される**調査メモ**を確認しながら、中謎・大謎に取り組みます。
6. 最後の扉を開くとクリア結果と、習得した考え方を確認できます。

ヒントは各問題3段階です。マップと自由メモがあり、時間制限はありません。ステージは最初の世界の**1つだけ**で、今後の世界は未実装です。

## 動かし方

### 最も簡単な方法

ZIPを展開して、`index.html` をブラウザで開いてください。外部APIやビルドツールは不要です。

ブラウザのセキュリティ設定により、ローカルファイル（`file://`）上ではセーブが使えない場合があります。**進行状況の保存まで確認するには、ローカルHTTPサーバーまたはGitHub Pagesを使ってください。**

### ローカルHTTPサーバーを使う場合

ZIPを展開したフォルダーでターミナルを開いて実行します。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` にアクセスします。Pythonがなければ、VS CodeのLive Serverなどでも構いません。

## GitHub Pagesで公開する方法

1. GitHubで**新しいリポジトリ**を作成します（Public推奨）。
2. ZIPを展開し、**中身**（`index.html`、`styles.css`、`js/`、`assets/` など）をリポジトリのルートにアップロードします。**ZIPファイルそのものをアップロードするだけでは動きません。**
3. `Settings` → `Pages` を開きます。
4. `Build and deployment` → `Source` を `Deploy from a branch` に設定します。
5. Branch を `main`、フォルダーを `/(root)` にして保存します。
6. GitHub Pagesに表示される公開URLへアクセスし、ゲームを開始できることを確認します。

通常、公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/` の形式です。**この納品物について、Git操作・公開操作は実行していません。**

## ファイル構成

```
index.html               ゲームのHTML
styles.css               ダーク／紫基調のUI、PC・スマホ対応
assets/
  favicon.svg             オリジナルの扉アイコン
  library-scene.webp      オリジナルの魔法図書館背景
js/
  data.js                 ステージ・謎・ヒント・解説のデータ
  app.js                  画面、状態管理、判定、セーブ処理
README.md                このファイル
TEST_REPORT.md           テスト結果と未検証事項
tests/
  test_playthrough.py     ブラウザE2Eの再実行用スクリプト
  screenshots/            検証時の画面キャプチャ
```

HTML・CSS・JavaScriptのみの静的構成です。サーバー、データベース、npmビルドは必要ありません。ゲーム用の通信API・課金機能・ログイン機能はありません。

## セーブデータ

- セーブ先：利用中ブラウザの `localStorage`
- 保存対象：謎の達成状況、所持品、各パズル途中の状態、ヒント使用回数、経過プレイ時間、自由メモ、設定、最高クリア記録
- 保存間隔：主な操作時に即時保存。ゲーム中は定期保存も行う
- 再開：次回アクセス時に「前回の続きから」を選択
- 初期化：設定 → 「このステージを最初からやり直す」
- 初期化時も自己ベストは保持

**他の端末やブラウザには同期されません。** ブラウザのデータ削除などで記録が消える可能性があります。

## 実装・コンテンツの留意点

- 8つの謎の**解答条件とヒント**は `js/data.js` と `js/app.js` で管理しています。
- 描画する問題の大半はSVGを使用しており、SVG内の図形をそのまま操作できます。
- 背景イラストは本プロジェクト向けに新規生成した独自素材です。外部の公式脱出ゲーム画像を利用していません。
- スマートフォンでは小さな背景内クリック領域に頼らず、画面下の調査ボタンから操作できます。
- 完成した問題データはJavaScript内にあるため、開発者ツールから解答に到達することは可能です。これは認証・ランキングの不正防止機構ではありません。
- 第1ステージの問題は導入編のため、**本番の高難度公演を再現するものではありません**。上達効果を測るには、未見の問題での検証が別途必要です。
